## 🎮 About GameSphere

GameSphere aims to bring independent games and players together in one place.

Whether you enjoy discovering new games or creating your own, GameSphere provides a home for gaming experiences.

Our mission is simple:

**Discover · Create · Play**

## ✨ Features

### 🔎 Discover Games
- Explore games shared by independent creators.
- Browse featured game collections.
- Find your next favorite game.

### 🕹️ Public Games
- Explore games published by the community.
- Play available HTML5 games.
- Discover different types of gaming experiences.

### 📚 My Games
- Keep track of your game collection.
- Access locally saved games.
- Manage saved game shortcuts in your browser.

### 📤 Publish Your HTML5 Games
GameSphere supports two upload formats:

- **HTML:** Upload a self-contained HTML5 game.
- **ZIP:** Upload a complete game export containing its HTML, JavaScript, images, audio, and other assets.
- **Thumbnail:** Add an image to represent your game.

Games can be played locally in the browser. Online publishing requires the appropriate hosting and backend configuration.

### 💾 Local Game Library
- Save uploaded game ZIPs in your browser.
- Play games locally.
- Keep game shortcuts on your device.
- Manage save slots for supported games.

## 📦 Local Development

Requirements:
- Node.js
- npm

Clone the repository:

```bash
git clone https://github.com/gamesphereofficial/gamesphereofficial.github.io.git
```

Enter the project directory:

```bash
cd gamesphereofficial.github.io
```

Install dependencies:

```bash
npm ci
```

Build the website:

```bash
npm run build
```

The generated website files are placed in the `dist` directory.

## 🔐 Security and Privacy

- Never commit passwords, API secrets, or private keys.
- Keep backend secrets outside browser-accessible JavaScript.
- Configure authentication providers and authorized domains correctly.
- Use secure backend services for online publishing and sensitive operations.
